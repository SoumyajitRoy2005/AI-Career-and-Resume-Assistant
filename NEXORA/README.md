# NEXORA
Your Career. Reimagined with AI.

## Run
1. Copy `.env.example` to `.env`.
2. Add your own Gemini API key to `GEMINI_API_KEY`.
3. `python -m venv venv`
4. Windows: `venv\Scripts\activate`
5. `pip install -r requirements.txt`
6. `streamlit run app.py`

Accounts and profiles are stored in local SQLite (`nexora.db`). The original Colab notebook is preserved in `reference/`.
